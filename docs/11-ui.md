# UI Dashboard — Frontend Spec

Showcase-ready web dashboard that makes the improvement loop visible: skill versions with diffs, agent execution traces, and the approval queue.

Reference implementation to adapt from: `/Users/amirali.iranmanesh/JB/OpenSpace/frontend/`

| Layer | Choice |

## Pages

### Dashboard (`/dashboard`)

Metrics row: **Total Skills** / **Avg Score** / **Total Runs** / **Pending Approvals**

Below: pipeline diagram (6 boxes with arrows: Bootstrap → Select → Execute → Analyze → Evolve → Approve), top-5 skills by score, recent 5 runs.

_Showcase value_: opens the demo showing the system is alive and learning.

---

### Skills Library (`/skills`)

Filter bar (All / Active / Pending / Superseded / Rejected), search, sort (Score / Updated / Selections).

Skill cards: name, category badge (`workflow` / `tool_guide` / `reference`), origin badge (`BOOTSTRAP` / `FIXED` / `DERIVED` / `CAPTURED`), generation number, effective-rate bar, selection count.

---

### Skill Detail (`/skills/:skillId`)

Two-column layout.

**Left**: metadata, quality metric bars (applied / completion / effective / fallback rate), current `SKILL.md` content.

**Right — Version history**: timeline gen 0 → gen N with origin, date, change summary, status badge. Click any version → load content. **Version compare**: pick two versions from dropdowns → split diff view.  Rollback button on each historical version.

**Right — Lineage graph**: node-link graph, nodes colored by status (active=green, pending=yellow, superseded=gray, rejected=red), sized by effective_rate.

**Diff viewer** (split, side-by-side): old on left / new on right, green add lines / red del lines / gray context, hunk headers with line numbers.

---

### Approval Queue (`/review`) — primary showcase page

Split layout: left = queue list, right = detail panel.

**Queue list** — sorted critical → high → medium → low:

Each card: `[PRIORITY] TYPE → skill-name vN→vN+1`, pattern key, recurrence count (`Seen 3× ▲` in orange when ≥ 2), date.

Priority badge colors: critical=red, high=orange, medium=gold, low=gray.
Type badge colors: FIX=blue, DERIVED=teal, CAPTURED=green.

Below evolutions: **Feature Requests** section with accept / defer / dismiss cards.

**Detail panel** (evolution selected):
- Direction text + change summary
- Split diff viewer (proposed vs parent)
- Benchmark PASS/FAIL badge
- Recurrence run list
- **Approve** (green) / **Reject** (red, prompts for reason) / **Edit & Approve** (inline editor)
- After action: remove from list, toast, auto-select next item

**Detail panel** (feature request selected):
- Capability + user context + complexity + priority
- Accept → triggers CAPTURED evolution / Defer / Dismiss

---

### Execution Traces (`/runs`, `/runs/:runId`)

**List**: task description, timestamp, status badge, iterations, selected skills as tags.

**Detail — three tabs**:

**Timeline** (default): vertical list of every agent step.
```
● iter 1  [assistant]  "I'll start by examining the diff..."
● iter 1  [tool]  get_pr_diff(pr=123)   340ms ✓
● iter 2  [tool]  search_code(...)      210ms ✓
● iter 3  [COMPLETE]
```
Each row expandable. Colors: assistant=blue, tool+success=green, tool+error=red, COMPLETE=bold green.

**Skills Used**: card per selected skill, `skill_applied` yes/no, analyzer note. Highlight not-applied skills.

**Analysis**: Trigger 1 output — task_completed, execution_note, tool_issues, evolution suggestions with links to the approval queue.

---

### Constitution (`/constitution`)

Rendered markdown of current constitution. Edit button → inline editor → save calls `PUT /api/v1/constitution`. Version history list with diffs.

---

## Demo Script

1. **Dashboard** — "After 50 runs the agent has 8 skills, 6 active."
2. **Runs → most recent run → Timeline tab** — "Here's exactly what it did, step by step."
3. **Analysis tab** — "Trigger 1 found one thing the agent missed."
4. **Review Queue** — "That produced this FIX proposal. The diff shows exactly what changes."
5. **Approve** — click. Queue count drops. Toast appears.
6. **Skill Detail** — open the skill, compare the two versions in the diff viewer.
7. **Constitution** — "This is what the agent can never evolve away from."
